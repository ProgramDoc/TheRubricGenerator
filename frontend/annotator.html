Proposed fields
ℹ️ How to fill out each field

Each row defines one piece of information you want Claude to pull out of every paper. Fill in the three text inputs, pick a type, and mark it required if it must be found in every paper.

Label
A short, human-readable name shown in the Results tab and in CSV exports. Write it the way you'd phrase it in a spreadsheet header. Example: Sample size, Primary outcome, Intervention dose.
ID (snake_case)
A short machine-friendly identifier — lowercase letters, numbers, and underscores only. Used as the column name in CSV exports and as the JSON key Claude returns. Example: sample_size, primary_outcome, intervention_dose. Must be unique within the schema.
Description
One-sentence hint telling Claude what to look for and where. This is the most important field for accuracy — be specific. Examples:
Total number of participants enrolled at randomization.
Pre-registered primary outcome (not secondary or exploratory).
Dose of the experimental intervention, including units.
Type
Tells Claude what kind of value to return. Pick the narrowest type that fits:
  • text — short free-form answer (a phrase or short sentence).
  • textarea — long free-form answer (multiple sentences).
  • number — a numeric value only (counts, percentages, durations, effect sizes).
  • date — a calendar date.
  • select — one of a small predefined set of options. When you pick this, an extra "Options" input appears — enter the allowed values as a comma-separated list (e.g. RCT, cohort, case-control).
  • boolean — yes/no question (Claude returns true or false).
Req. (required)
When checked, Claude must provide a value for this field on every paper. Leave unchecked for fields that may not apply (e.g. "Blinding method" doesn't apply to observational studies).

Tip: Claude extracts better when Description is specific. "Number of participants" is vaguer than "Total N enrolled at baseline (ITT population)." Don't write instructions for the AI here — just describe the target piece of information.
