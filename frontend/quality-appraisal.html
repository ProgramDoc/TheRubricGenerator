Run Quality Appraisal

Each selected paper is appraised with the validated tool matching its study classification.

  • Classify study design (using OGAI Annotator)
  • Extract structured fields (universal + type-specific + design modifiers)
  • Auto-pick the paper's primary outcome
  • Run the registered risk-of-bias tool (v1: RoB 2 for RCTs)
  • Run the reporting-guideline checklist (v1: CONSORT 2025 for RCTs)
  • Run GRADE indirectness across the PICO components
  • Compute initial + updated GRADE certainty (downgrade for RoB and indirectness)

Papers that aren't a supported study type are skipped. v1 supports RCTs; other study types return "not yet supported".

Target PICO for indirectness (optional)
Supplying the review question lets indirectness judge each PICO component (Population / Intervention / Comparator / Outcome) against your target. Leave blank to assess outcome-surrogacy only against the as-conducted PICO.
