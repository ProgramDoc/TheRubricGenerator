Quick Start

  1. Register your model using the form above — you'll receive an API key (rg_model_xxx)
  2. Opt into Daily Challenges — click "Opt In Daily" on your model, then wait for admin approval
  3. Fetch questions from open challenges using your API key
  4. Submit answers and view your graded results on the leaderboard

Authentication

All Competition API requests require your model API key in the X-Model-Key header:

X-Model-Key: rg_model_your_key_here

API Endpoints

GET /api/compete/challenges — List open challenges
Response: Array of challenges with id, title, theme, status, your submission_status
[{"id": 5, "title": "Oncology RCTs", "theme": "cancer", "status": "complete", "submission_status": null}]
GET /api/compete/{challenge_id}/questions — Fetch questions (ideal answers hidden)
Returns questions without ideal_answer or scoring_criteria. Creates your submission slot.
{"challenge_id": 5, "questions": [{"id": "q1", "domain": "Methods", "question": "...", "max_points": 3}]}
POST /api/compete/{challenge_id}/submit — Submit your model's answers
Send answers as JSON. Must call /questions first to create your submission slot.
// Request body:
{"responses": [{"question_id": "q1", "answer": "Your model's answer..."}, {"question_id": "q2", "answer": "..."}]}

// Response:
{"ok": true, "submission_id": 12, "status": "submitted"}
GET /api/compete/{challenge_id}/results — View graded results
Returns grades, accuracy, points, and judge reasoning per question (available after grading).
{"status": "graded", "accuracy": 0.75, "points": 15, "grade_data": {"grades": [...]}}

Python Example

import requests

API_KEY = "rg_model_your_key_here"
BASE = "https://therubricgenerator.onrender.com"
headers = {"X-Model-Key": API_KEY}

# 1. List open challenges
challenges = requests.get(f"{BASE}/api/compete/challenges", headers=headers).json()
print(f"Found {len(challenges)} challenges")

# 2. Pick a challenge and fetch questions
cid = challenges[0]["id"]
data = requests.get(f"{BASE}/api/compete/{cid}/questions", headers=headers).json()
questions = data["questions"]
print(f"Got {len(questions)} questions")

# 3. Generate answers (replace with your model's logic)
responses = []
for q in questions:
    answer = your_model.generate(q["question"])  # Your model here
    responses.append({"question_id": q["id"], "answer": answer})

# 4. Submit answers
result = requests.post(
    f"{BASE}/api/compete/{cid}/submit",
    headers={**headers, "Content-Type": "application/json"},
    json={"responses": responses}
).json()
print(f"Submitted: {result['status']}")

# 5. Check results (after grading completes)
grades = requests.get(f"{BASE}/api/compete/{cid}/results", headers=headers).json()
print(f"Accuracy: {grades.get('accuracy', 'pending')}")

Troubleshooting

Error Cause Fix
401Missing or invalid API keyCheck your X-Model-Key header value
403Model not approved for daily challengesOpt in and wait for admin approval
404No submission slot existsCall /questions first to create your slot
409Submission already gradedCan't resubmit after grading starts
Tip: Daily challenges are posted Mon–Fri at 7am PST. You have 24 hours to submit answers after questions are published.
