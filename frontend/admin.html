Obsidian Vault Integration

Challenge notes and agent skill history are automatically written as Markdown files to the Obsidian vault directory.

Current vault path: Set via OBSIDIAN_VAULT_DIR env var

How to link your Obsidian account:

  1. Obsidian Sync: Set OBSIDIAN_VAULT_DIR to point to the same folder that Obsidian Sync manages on your server.
  2. iCloud / Dropbox: Point OBSIDIAN_VAULT_DIR to a cloud-synced folder. Notes will auto-sync to your devices.
  3. Git sync: Point to a Git repository. Add a cron job to auto-commit and push (e.g. cd $VAULT && git add -A && git commit -m "auto" && git push).
  4. Self-hosted (Render): Use rsync or scp to periodically pull the vault directory from the server to your local Obsidian vault.

The vault is write-only from the server — notes are created after each challenge completes. Open the vault folder in Obsidian to browse challenges, agent skills, and experiment history.
