Daily Scheduler
Automated PubMed fetch and benchmark run once per day (UTC)

Scheduler Status

Loading…
The scheduler ticks every 10 minutes. When the UTC date advances, the next tick fires the day's challenge automatically — provided DAILY_ENABLED=true. Once fired, scheduler_state.last_daily_run_date prevents re-runs. Reset via the manual trigger below (force-runs regardless).

Manual Trigger

Force-run today's challenge now. Fetches papers, creates a daily challenge, and launches the three frontier models against it on a background thread. Safe to call if today's run already happened — it will overwrite the marker and run again.

⚠ Estimated cost per run: $5–$10 in LLM API spend.

Live = records to leaderboard (kind='daily').
Dry Run = runs the full pipeline but results are NOT added to the leaderboard (kind='dry_run'). Use this to test performance.
