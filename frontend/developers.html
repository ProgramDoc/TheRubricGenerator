🚀 Quick Start

  1. Generate your API key above
  2. Add the header to every request: X-API-Key: rg_user_your_key
  3. Call any endpoint — challenges, papers, rubrics, evaluations, search

curl Example

curl -H "X-API-Key: rg_user_your_key" \
  https://therubricgenerator.onrender.com/api/challenges

Python Example

import requests

API_KEY = "rg_user_your_key"
BASE = "https://therubricgenerator.onrender.com"
headers = {"X-API-Key": API_KEY}

# List your challenges
challenges = requests.get(f"{BASE}/api/challenges", headers=headers).json()
print(f"You have {len(challenges)} challenges")

# Upload a PDF
with open("paper.pdf", "rb") as f:
    r = requests.post(f"{BASE}/api/papers/upload", headers=headers, files={"file": f})
    paper_id = r.json()["id"]
    print(f"Uploaded paper #{paper_id}")

# Create and run a challenge
challenge = requests.post(f"{BASE}/api/challenges", headers=headers, json={
    "title": "My API Challenge",
    "theme": "oncology",
    "paper_ids": [paper_id],
    "participant_models": ["claude-opus-4-20250514"],
}).json()

# Run it
requests.post(f"{BASE}/api/challenges/{challenge['challenge_id']}/run",
              headers=headers, json={"approved": True})

# Check results (poll until complete)
import time
while True:
    result = requests.get(f"{BASE}/api/challenges/{challenge['challenge_id']}",
                         headers=headers).json()
    if result["status"] in ("complete", "failed"):
        break
    time.sleep(10)

print(f"Status: {result['status']}")
for p in result.get("participants", []):
    print(f"  {p['model_id']}: {p['accuracy']:.1%} accuracy")

📖 API Reference

Authentication: All endpoints accept X-API-Key header. Browser sessions (cookies) also work — the API key is an alternative for programmatic access.

Challenges

POST/api/challengesCreate a new challenge
// Request body
{"title": "My Test", "theme": "oncology", "paper_ids": [1, 2], "participant_models": ["claude-opus-4-20250514"]}

// Response
{"challenge_id": 5}
GET/api/challengesList your challenges
GET/api/challenges/{id}Get challenge details, rubric, results
POST/api/challenges/{id}/runStart running a challenge
{"approved": true}  // Required if cost > $5
POST/api/challenges/{id}/cancelCancel a running challenge
DELETE/api/challenges/{id}Delete a private challenge
GET/api/challenges/{id}/eventsReal-time progress events

Papers

POST/api/papers/uploadUpload a PDF (multipart form)
curl -H "X-API-Key: rg_user_xxx" \
  -F "file=@paper.pdf" -F "project_id=1" \
  https://site/api/papers/upload
GET/api/papersList your uploaded papers
DELETE/api/papers/{id}Delete a paper

Rubrics

POST/api/rubrics/generateGenerate rubric from a paper
{"paper_id": 1, "rubric_type": "classification"}
GET/api/rubrics?paper_id=NList rubrics for a paper
PUT/api/rubrics/{id}Update a rubric

Evaluations

POST/api/evaluations/runRun LLM evaluation against a rubric
{"rubric_id": 1, "paper_id": 1, "eval_model": "gpt-5.4"}
GET/api/evaluations/{id}Get evaluation results
GET/api/evaluations/{id}/exportDownload results as CSV

Search

POST/api/search/chatAI search strategist (generates PubMed queries)
{"message": "Find RCTs comparing ACE inhibitors to ARBs in elderly patients"}
POST/api/search/executeRun search on PubMed or Europe PMC
{"session_id": 1, "database": "pubmed", "query": "cancer AND randomized", "page": 1}
POST/api/search/importImport search results as papers
{"session_id": 1, "result_ids": [1, 2, 3], "project_id": 1}
