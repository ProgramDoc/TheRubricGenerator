Versioned published targets

Reference effects are compared on the analysis scale: logarithms for RR, OR and HR; original units for MD, SMD and RD. Confidence bounds are checked independently. The default tolerance is exploratory and can be prespecified per outcome.

Each imported file creates an immutable revision. Runs snapshot that revision; later imports cannot change an earlier score. Domain agreement is calculated only where a published domain-level target exists.

Add or curate a benchmark

Start with a downloaded reference, verify the model and interval method, add primary-study identifiers and expected extraction data, then obtain independent review. Use a study key to map each uploaded PDF to its reference record.

To mark a benchmark adjudicated, include a study manifest, verified pooling settings and two distinct reviewer names. This is a recorded attestation, not independent verification by the platform.

Test the stages, then the system

  1. Freeze the question. Prespecify PICO, outcome, comparison, timepoint, effect direction, eligible study set, pooling method and tolerance.
  2. Separate inputs from answers. Agents receive primary reports and the question. The deterministic evaluator receives the published reference after the run.
  3. Attribute errors. Compare classification and inclusion first, then extraction and RoB, pooled effects, intervals and GRADE. A wrong study set can explain a wrong pooled estimate.
  4. Repeat without edits. Use 3–5 independent runs to quantify disagreement across repeats. Compare implementations on the same frozen cases.
  5. Hold out reviews. Split at the review/topic level; related reports from one trial stay together. Public papers may appear in model training, so this is a reproduction benchmark, not proof of unseen-data generalization.

Interpret agreement carefully

  • Exact GRADE agreement, ordinal distance and overconfidence complement weighted kappa; none alone validates guideline adherence.
  • Published reviews can contain errors. Two reviewers should adjudicate effect direction, timepoints, study overlap, missing data and GRADE rationales.
  • Numerical differences may reflect REML versus DL, fixed versus random effects, interval method or continuity correction. Verify settings before declaring a regression.
  • Test missing answers, invalid JSON, conflicting reports, incomplete RoB, duplicate cohorts, zero events, cluster designs and service failures.
  • Retain abstentions and failed jobs. Never present a missing assessment as a clean domain.
